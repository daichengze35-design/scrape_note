Web API 加密逻辑分析
    第 1 阶段：JavaScript 必要基础

    学习目标
        能阅读前端代码中的变量、对象、函数、闭包、this、Promise、async 和 await
        能区分 JavaScript 字符串、UTF-16 码元、Unicode 码点和 UTF-8 字节
        能阅读 ArrayBuffer、TypedArray、DataView、JSON 和 Base64 相关代码
        能判断一段同步代码与 Promise 后续代码的执行顺序
        能识别浏览器运行时、Node.js 运行时和 ECMAScript 语言本身的边界

    本阶段不学习
        不使用 Network、Sources、断点、调用栈或其他 DevTools 调试操作
        不调用 fetch、XHR、WebSocket 或任何接口
        不处理请求头、Cookie、Token、参数排序或请求重放
        不学习哈希、HMAC、AES、RSA、Web Crypto、CryptoJS 或签名还原
        不学习 webpack、Source Map、压缩代码、混淆、Worker、WASM、GraphQL 或 Protobuf

    示例输出格式
        固定输出按照现有笔记约定，写在 console.log(...) 后两个 Tab 的 # 后面
        # 后面的内容是教程中的输出标注，不属于 JavaScript 注释语法
        复制示例到 JavaScript 运行时执行时，需要移除 # 及其后的输出标注

    JavaScript、ECMAScript 与运行时
        ECMAScript
            ECMAScript 是 JavaScript 语言规范
            变量、函数、对象、Promise、class 和 module 等语言特性由 ECMAScript 规定
        JavaScript
            JavaScript 是对 ECMAScript 的实现和日常称呼
            浏览器中的 JavaScript 除了 ECMAScript，还可以使用浏览器提供的 Web API
        术语修正
            “JavaScript 是对 ECMAScript 的实现”是便于入门的简化表述
            更精确地说，JavaScript 是遵循 ECMAScript 规范的语言及其通用名称
            V8、SpiderMonkey、JavaScriptCore 等 JavaScript 引擎才是规范的具体实现
            浏览器和 Node.js 在语言引擎之外继续提供各自的宿主 API
        浏览器 Web API
            DOM、document、window、localStorage、TextEncoder、atob 和 btoa 等由浏览器环境提供
            Web API 不等于 ECMAScript 语言本身
        Node.js
            Node.js 是另一个 JavaScript 运行时
            Node.js 不默认提供浏览器的 document、window 和 DOM
            同一个 JavaScript 文件能否运行，取决于它使用的 API 是否被当前运行时提供
        globalThis
            globalThis 是标准的全局对象访问入口
            浏览器中 globalThis 通常与 window 指向同一个全局对象
            Node.js 中 globalThis 存在，但 window 通常不存在
        重点
            阅读前端代码时，先区分“语言语法”和“浏览器 API”
            看到 document、location、localStorage 时，应知道它们依赖浏览器环境
            看到 require、module.exports 时，应知道它们通常属于 CommonJS 生态，不是原生浏览器 ESM 语法

    脚本与模块
        经典脚本
            传统 script 标签加载的代码通常称为经典脚本
            经典脚本的顶层声明与全局对象之间可能存在关系，具体取决于声明方式和运行环境
        ES Module
            使用 import 或 export 的文件是 ES Module
            ES Module 有自己的模块作用域
            ES Module 默认使用严格模式
            ES Module 中的顶层 await 只在支持该语法的模块环境中可用
        模块身份的精确判断
            静态 import 声明和 export 声明只能出现在 ES Module 中
            动态 import() 是表达式，也可以出现在允许该语法的经典脚本中
            一个不含静态 import 或 export 的文件，仍可由 script type="module"、.mjs 扩展名或运行时配置作为 ES Module 加载
            因此模块身份最终由宿主加载方式和运行时配置决定，不能只依靠文件内容中的单个关键词判断
        重点
            后续阅读代码时，先确认文件是经典脚本、ES Module 还是打包后的模块代码
            不要把一个文件中的顶层变量默认当成所有文件都能访问的全局变量

    注释与语句
        单行注释
            // 后面的内容是单行注释
        多行注释
            /* 和 */ 之间的内容是多行注释
        语句结束
            JavaScript 在许多位置会自动插入分号
            为避免换行含义不明确，学习和编写基础示例时可以显式写分号
        标识符
            变量、函数、类和属性可使用有意义的名称
            JavaScript 区分大小写
            user、User 和 USER 是三个不同的标识符

    变量声明
        const
            const 声明的变量不能重新绑定到另一个值
            const 声明必须在声明时初始化
            const 不表示对象或数组内容不可改变
        let
            let 声明的变量可以重新赋值
            let 具有块级作用域
        var
            var 具有函数作用域，不具有块级作用域
            新代码通常优先使用 const，需要重新赋值时使用 let
            阅读旧代码时仍会遇到 var
        e.g.
            const name = "Lin";
            let count = 1;
            count = 2;
            console.log(name);		# Lin
            console.log(count);		# 2
        const 与对象内容
            const 只限制变量绑定，不冻结对象内容
        e.g.
            const user = { name: "Lin" };
            user.name = "Qin";
            console.log(user.name);		# Qin
        错误写法
            const user = { name: "Lin" };
            user = { name: "Qin" };
            上述第二行会抛出 TypeError，因为 const 变量不能重新赋值

    作用域
        概念
            作用域决定一个标识符在什么代码范围内可被访问
        全局作用域
            在模块外部或运行时全局位置声明的值可能位于全局作用域
            不同脚本、模块和运行时对顶层声明的可见性规则不同
        函数作用域
            函数内部声明的变量通常只在该函数及其内部作用域中可见
        块级作用域
            使用 let 或 const 在 {} 块中声明的变量只在该块中可见
        e.g.
            const outside = "outer";
            if (true) {
                const inside = "inner";
                console.log(outside);		# outer
                console.log(inside);		# inner
            }
            outside 可以在块内访问
            inside 不能在块外访问
        var 与块级作用域
            var 不遵守上述块级作用域规则
        e.g.
            if (true) {
                var legacyValue = "visible outside block";
            }
            console.log(legacyValue);		# visible outside block
        遮蔽
            内层作用域可以声明与外层同名的变量
            内层同名变量会遮蔽外层变量
        e.g.
            const value = "outer";
            function showValue() {
                const value = "inner";
                return value;
            }
            console.log(showValue());		# inner
            console.log(value);		# outer

    提升与暂时性死区
        函数声明提升
            函数声明在其所在作用域中可以在声明语句前调用
        e.g.
            console.log(add(1, 2));		# 3
            function add(a, b) {
                return a + b;
            }
        var 提升
            var 的声明会被提升，但赋值不会被提升
            在赋值前读取 var 变量，通常得到 undefined
        e.g.
            console.log(message);		# undefined
            var message = "ready";
        let 与 const
            let 和 const 的声明也会被处理，但在初始化前不能访问
            从作用域开始到初始化完成前的区域称为暂时性死区
            在暂时性死区中访问 let 或 const 会抛出 ReferenceError
        重点
            阅读压缩代码时，不要因为声明在后面就假设变量未被使用
            需要结合声明类型、作用域和赋值位置判断实际值

    JavaScript 数据类型
        原始类型
            undefined
                表示尚未赋值、缺少属性或没有明确返回值等状态
            null
                表示明确的空值
            boolean
                只有 true 和 false
            number
                包括整数、浮点数、NaN、Infinity 和 -Infinity
            bigint
                用于任意精度整数，例如 123n
            string
                文本值
            symbol
                唯一标识值，常用于特殊对象属性
        对象类型
            object
                普通对象、数组、日期、Map、Set 等均属于对象值
            function
                函数是可调用对象，typeof 函数返回 "function"
        typeof
            typeof 用于查看运行时类型标签
        e.g.
            console.log(typeof undefined);		# undefined
            console.log(typeof "text");		# string
            console.log(typeof 1);		# number
            console.log(typeof 1n);		# bigint
            console.log(typeof true);		# boolean
            console.log(typeof {});		# object
            console.log(typeof []);		# object
            console.log(typeof function () {});		# function
        null 的历史行为
            typeof null 的结果是 "object"
            这是 JavaScript 保留的历史行为，不能据此把 null 当作普通对象
        e.g.
            console.log(typeof null);		# object
            console.log(null === null);		# true
        数组判断
            不能只用 typeof 判断数组
            使用 Array.isArray() 判断一个值是否为数组
        e.g.
            console.log(Array.isArray([]));		# true
            console.log(Array.isArray({}));		# false

    undefined、null、NaN
        undefined
            未显式赋值的 let 变量初始值是 undefined
            不存在的对象属性读取结果通常是 undefined
        null
            由代码明确设置，用于表达“当前没有值”
        e.g.
            let pending;
            const selected = null;
            console.log(pending === undefined);		# true
            console.log(selected === null);		# true
        NaN
            NaN 表示 Not-a-Number
            NaN 的类型仍然是 number
            NaN 不等于自身
            使用 Number.isNaN() 判断 NaN
        e.g.
            const result = Number("not a number");
            console.log(typeof result);		# number
            console.log(result === result);		# false
            console.log(Number.isNaN(result));		# true

    真值与假值
        假值
            false
            0
            -0
            0n
            ""
            null
            undefined
            NaN
        真值
            除假值外的大多数值都是真值
            空数组 [] 和空对象 {} 都是真值
        e.g.
            console.log(Boolean(0));		# false
            console.log(Boolean(""));		# false
            console.log(Boolean([]));		# true
            console.log(Boolean({}));		# true
        ||
            左侧为假值时返回右侧
        ??
            左侧为 null 或 undefined 时返回右侧
            0、"" 和 false 不会触发 ?? 的右侧
        e.g.
            console.log(0 || "default");		# default
            console.log(0 ?? "default");		# 0
            console.log("" || "default");		# default
            console.log("" ?? "default");		# 
        可选链
            ?. 用于在左侧为 null 或 undefined 时停止属性访问并返回 undefined
        e.g.
            const user = { profile: { name: "Lin" } };
            console.log(user.profile?.name);		# Lin
            console.log(user.contact?.phone);		# undefined
        重点
            ||、?? 和 ?. 不会进行密码学处理
            它们常出现在前端参数默认值、嵌套数据读取和配置合并代码中

    比较与相等
        ===
            严格相等比较，不进行隐式类型转换
        !==
            严格不相等比较
        ==
            宽松相等比较，可能进行类型转换
        !=
            宽松不相等比较，可能进行类型转换
        建议
            阅读和编写基础逻辑时优先使用 === 与 !==
        e.g.
            console.log(1 === "1");		# false
            console.log(1 == "1");		# true
            console.log(null == undefined);		# true
            console.log(null === undefined);		# false
        Object.is
            Object.is() 在少数边界值上与 === 不同
            Object.is(NaN, NaN) 为 true
            Object.is(0, -0) 为 false
        e.g.
            console.log(Object.is(NaN, NaN));		# true
            console.log(Object.is(0, -0));		# false

    Number、BigInt 与位运算
        Number
            JavaScript 的普通数值使用 IEEE 754 双精度浮点数表示
            一些十进制小数不能被二进制浮点数精确表示
        e.g.
            console.log(0.1 + 0.2 === 0.3);		# false
        安全整数
            Number 能精确表示的整数范围由 Number.MAX_SAFE_INTEGER 限制
            Number.MAX_SAFE_INTEGER 是 9007199254740991
            超出安全整数范围后，不应假设每一个相邻整数都能被精确区分
        e.g.
            console.log(Number.MAX_SAFE_INTEGER);		# 9007199254740991
            console.log(Number.isSafeInteger(9007199254740991));		# true
            console.log(Number.isSafeInteger(9007199254740992));		# false
        BigInt
            BigInt 用于任意精度整数，字面量通常以 n 结尾
            Number 与 BigInt 不能直接进行算术运算
        e.g.
            console.log(9007199254740993n + 1n);		# 9007199254740994n
        位运算
            对 Number 使用位运算时，JavaScript 会按 32 位整数规则处理操作数
            位运算常见于字节处理和旧代码中的整数变换
            >>> 是无符号右移，只适用于 Number，不适用于 BigInt
        e.g.
            console.log(0xff & 0x0f);		# 15
            console.log(1 << 8);		# 256
            console.log(-1 >>> 0);		# 4294967295
        重点
            看到 |、&、^、<<、>>、>>> 时，先确认代码是否在处理 32 位整数
            位运算结果不能直接等同于任意精度数学整数结果

    字符串、UTF-16 码元、Unicode 码点与 UTF-8 字节
        JavaScript 字符串
            JavaScript 字符串是不可变文本值
            修改字符串方法的结果会返回新字符串，原字符串不会被原地修改
            JavaScript 字符串的 length 和下标访问基于 UTF-16 码元
        UTF-16 码元
            UTF-16 码元是 JavaScript 字符串内部索引使用的单位
            某些 Unicode 字符需要两个 UTF-16 码元表示
        Unicode 码点
            Unicode 码点是字符的编号
            一个码点不一定等于一个 UTF-16 码元
        UTF-8 字节
            UTF-8 是把字符编码为字节的规则
            JavaScript 字符串不是“UTF-8 字节数组”
        e.g.
            const text = "A😀";
            console.log(text.length);		# 3
            console.log(Array.from(text).length);		# 2
            console.log(text.codePointAt(1).toString(16));		# 1f600
        charCodeAt()
            charCodeAt(index) 返回指定 UTF-16 码元的数值
            charCodeAt() 不返回 UTF-8 字节
        codePointAt()
            codePointAt(index) 返回从指定位置开始的 Unicode 码点数值
            codePointAt() 不返回 UTF-8 字节
        TextEncoder
            TextEncoder 把 JavaScript 字符串编码为 UTF-8 字节
            encode() 返回 Uint8Array
        e.g.
            const bytes = new TextEncoder().encode("你");
            console.log(bytes.length);		# 3
            console.log(Array.from(bytes).join(","));		# 228,189,160
        TextDecoder
            TextDecoder 把字节按指定编码解码为 JavaScript 字符串
            不指定编码时通常使用 UTF-8
        e.g.
            const bytes = new Uint8Array([228, 189, 160]);
            const text = new TextDecoder("utf-8").decode(bytes);
            console.log(text);		# 你
        重点
            字符数量、UTF-16 码元数量和 UTF-8 字节数量可能不同
            后续需要比较字节时，不能只比较 string.length

    常用字符串操作
        模板字符串
            使用反引号包围
            ${表达式} 会把表达式结果插入字符串
        e.g.
            const name = "Lin";
            const message = `hello ${name}`;
            console.log(message);		# hello Lin
        字符串不可变
        e.g.
            const source = "  Lin  ";
            const trimmed = source.trim();
            console.log(source);		#   Lin  
            console.log(trimmed);		# Lin
        常用方法
            slice(start, end) 返回指定范围的新字符串
            toLowerCase() 和 toUpperCase() 返回大小写转换后的新字符串
            includes(value) 判断是否包含子串
            replace(oldValue, newValue) 返回替换后的新字符串
        e.g.
            const value = "abc123";
            console.log(value.slice(0, 3));		# abc
            console.log(value.includes("c1"));		# true
            console.log(value.replace("123", "456"));		# abc456

    数组
        概念
            数组是有顺序的对象集合
            数组下标从 0 开始
            数组是对象，因此赋值给另一个变量时复制的是引用值
        e.g.
            const values = ["a", "b", "c"];
            console.log(values[0]);		# a
            console.log(values.length);		# 3
        常用操作
            push() 在末尾增加元素，并修改原数组
            pop() 删除末尾元素，并修改原数组
            slice() 返回新数组，不修改原数组
            map() 返回每个元素转换后的新数组
            filter() 返回满足条件的新数组
            find() 返回第一个满足条件的元素，未找到时返回 undefined
            reduce() 把多个元素归并为一个结果
        e.g.
            const values = [1, 2, 3, 4];
            const doubled = values.map((value) => value * 2);
            const evenValues = values.filter((value) => value % 2 === 0);
            const firstOverTwo = values.find((value) => value > 2);
            const total = values.reduce((sum, value) => sum + value, 0);
            console.log(doubled.join(","));		# 2,4,6,8
            console.log(evenValues.join(","));		# 2,4
            console.log(firstOverTwo);		# 3
            console.log(total);		# 10
        for...of
            for...of 遍历可迭代对象的值
            数组通常使用 for...of 遍历值
        e.g.
            const values = [2, 4, 6];
            let total = 0;
            for (const value of values) {
                total += value;
            }
            console.log(total);		# 12

    对象与属性
        概念
            对象由属性组成
            属性名通常是字符串或 Symbol
        属性访问
            obj.name 使用固定属性名
            obj["name"] 使用字符串属性名
            obj[key] 使用变量计算出的属性名
        e.g.
            const user = { name: "Lin", level: 2 };
            const key = "name";
            console.log(user.name);		# Lin
            console.log(user["level"]);		# 2
            console.log(user[key]);		# Lin
        计算属性名
            对象字面量中可以使用 [expression] 创建计算出的属性名
        e.g.
            const field = "status";
            const result = { [field]: "ok" };
            console.log(result.status);		# ok
        自有属性
            自有属性直接存在于对象本身
            Object.hasOwn(object, key) 判断对象是否具有指定自有属性
        e.g.
            const user = { name: "Lin" };
            console.log(Object.hasOwn(user, "name"));		# true
            console.log(Object.hasOwn(user, "toString"));		# false
        Object.keys()
            Object.keys() 返回对象自身可枚举字符串属性名组成的数组
        e.g.
            const user = { name: "Lin", level: 2 };
            console.log(Object.keys(user).join(","));		# name,level

    引用值、复制与参数传递
        原始值
            number、string、boolean、null、undefined、bigint、symbol 是原始值
            原始值赋值时，变量得到该值本身
        引用值
            对象和数组是引用值
            两个变量可以保存指向同一对象的引用值
        e.g.
            const original = { level: 1 };
            const alias = original;
            alias.level = 2;
            console.log(original.level);		# 2
        参数传递
            JavaScript 函数参数始终按值传递
            对象变量中的“值”是一个引用值，因此函数可以通过该引用修改对象内容
            给函数参数重新赋值，不会让调用方变量改为指向新对象
        e.g.
            function replaceLocal(value) {
                value = { level: 9 };
                return value.level;
            }
            const source = { level: 1 };
            console.log(replaceLocal(source));		# 9
            console.log(source.level);		# 1
        浅拷贝
            {...object}、Object.assign() 和 [...array] 都只进行浅拷贝
            浅拷贝会复制最外层属性或元素，嵌套对象仍可能共享同一引用值
        e.g.
            const original = { profile: { level: 1 } };
            const copied = { ...original };
            copied.profile.level = 2;
            console.log(original.profile.level);		# 2
        重点
            阅读参数构造代码时，要判断对象是原地修改，还是创建了新对象
            不能把对象行为描述为“对象按引用传递”，JavaScript 参数传递始终是值传递

    解构、rest 与 spread
        对象解构
            从对象中取出属性并赋值给变量
        e.g.
            const user = { name: "Lin", level: 2 };
            const { name, level } = user;
            console.log(name);		# Lin
            console.log(level);		# 2
        数组解构
            从数组中按位置取值
        e.g.
            const values = [10, 20, 30];
            const [first, , third] = values;
            console.log(first);		# 10
            console.log(third);		# 30
        rest
            在解构中，...rest 收集剩余属性或元素
            在函数参数中，...values 收集额外传入的参数
        e.g.
            const user = { id: 1, name: "Lin", level: 2 };
            const { id, ...profile } = user;
            console.log(id);		# 1
            console.log(profile.name);		# Lin
            console.log(profile.level);		# 2
        spread
            在数组或对象字面量中，...source 展开可迭代值或对象属性
            对象 spread 后方同名属性会覆盖前方属性
        e.g.
            const defaults = { language: "zh", level: 1 };
            const settings = { ...defaults, level: 2 };
            console.log(settings.language);		# zh
            console.log(settings.level);		# 2
        重点
            rest 与 spread 都使用 ...，具体含义取决于出现的位置
            spread 不会自动进行深拷贝

    函数
        函数声明
            function name() {} 是函数声明
        函数表达式
            const name = function () {} 是函数表达式
        箭头函数
            const name = () => {} 是箭头函数
        e.g.
            function addOne(value) {
                return value + 1;
            }
            const addTwo = function (value) {
                return value + 2;
            };
            const addThree = (value) => value + 3;
            console.log(addOne(1));		# 2
            console.log(addTwo(1));		# 3
            console.log(addThree(1));		# 4
        默认参数
            调用方未传入或传入 undefined 时，使用默认参数值
        e.g.
            function makeLabel(name, prefix = "user") {
                return `${prefix}:${name}`;
            }
            console.log(makeLabel("Lin"));		# user:Lin
            console.log(makeLabel("Lin", "admin"));		# admin:Lin
        rest 参数
            rest 参数把多余实参收集为数组
        e.g.
            function sum(...values) {
                return values.reduce((total, value) => total + value, 0);
            }
            console.log(sum(1, 2, 3));		# 6
        返回对象的箭头函数
            箭头函数直接返回对象字面量时，需要用 () 包围对象
        e.g.
            const makeUser = (name) => ({ name, level: 1 });
            console.log(makeUser("Lin").name);		# Lin
            console.log(makeUser("Lin").level);		# 1

    回调与高阶函数
        回调函数
            回调函数作为参数传给另一个函数，并由该函数在合适时机调用
        高阶函数
            接收函数作为参数，或返回函数的函数
        e.g.
            function applyTwice(value, transform) {
                return transform(transform(value));
            }
            const result = applyTwice(2, (value) => value + 3);
            console.log(result);		# 8
        常见位置
            map、filter、reduce、then、catch 和事件处理代码都常接收回调函数
        重点
            阅读回调时，要分别确认“回调在哪里定义”“谁调用它”“调用时传入什么参数”

    闭包
        概念
            闭包是函数及其创建时可访问的词法作用域组合
            内部函数可以在外层函数返回后继续访问外层变量
        e.g.
            function createCounter() {
                let count = 0;
                return function () {
                    count += 1;
                    return count;
                };
            }
            const next = createCounter();
            console.log(next());		# 1
            console.log(next());		# 2
        作用
            保存私有状态
            生成带预设配置的函数
            在异步回调中保留创建时的变量访问能力
        重点
            闭包不会复制外层变量的一个固定快照
            闭包访问的是词法作用域中的变量绑定，因此变量后续变化可以被读取到

    IIFE
        概念
            IIFE 是立即调用函数表达式
            它在定义后立即执行
        e.g.
            const value = (() => {
                const hidden = 3;
                return hidden * 2;
            })();
            console.log(value);		# 6
        阅读意义
            旧版前端代码和打包代码中可能用 IIFE 创建局部作用域
            看到 (function () {})() 或 (() => {})() 时，应先识别它是立即执行而不是普通函数定义

    this
        普通函数的 this
            普通函数的 this 由调用方式决定
            obj.method() 形式调用时，method 内的 this 通常指向 obj
            严格模式下，脱离对象直接调用普通函数时，this 是 undefined
        e.g.
            function getName() {
                return this.name;
            }
            const user = { name: "Lin", getName };
            console.log(user.getName());		# Lin
        call()
            fn.call(thisArg, arg1, arg2) 立即调用函数，并明确指定 this
        apply()
            fn.apply(thisArg, argsArray) 立即调用函数，并把参数放在数组或类数组中传入
        bind()
            fn.bind(thisArg) 返回一个 this 已绑定的新函数
        e.g.
            function describe(prefix) {
                return `${prefix}:${this.name}`;
            }
            const context = { name: "Lin" };
            const bound = describe.bind(context, "user");
            console.log(describe.call(context, "admin"));		# admin:Lin
            console.log(describe.apply(context, ["guest"]));		# guest:Lin
            console.log(bound());		# user:Lin
        箭头函数的 this
            箭头函数没有自己的 this
            箭头函数使用创建位置所在词法作用域中的 this
            箭头函数不是“自动绑定当前对象”
        注意
            对象字面量中的方法如果需要通过 this 读取该对象属性，通常使用普通方法语法或普通函数
            class 方法默认是普通方法；把它单独作为回调传递时，需要确认 this 是否仍然正确

    new 与构造调用
        普通调用
            fn(args) 是普通函数调用
            普通函数中的 this 由调用方式和严格模式规则决定
        构造调用
            new Constructor(args) 是构造调用
            构造调用会创建新对象，并让新对象的原型关联到 Constructor.prototype
            构造函数执行时，this 指向新创建的对象
            构造函数没有显式返回对象时，new 表达式返回新创建的对象
            构造函数显式返回另一个对象时，new 表达式返回该对象
        e.g.
            function Profile(name) {
                this.name = name;
            }
            Profile.prototype.label = function () {
                return `profile:${this.name}`;
            };
            const profile = new Profile("Lin");
            console.log(profile.label());		# profile:Lin
        class 与 new
            class 必须通过 new 进行构造调用，不能作为普通函数直接调用
            class 的 constructor 用于初始化实例
        不可构造函数
            并非所有函数值都能与 new 一起使用
            箭头函数没有 [[Construct]] 内部能力，不能作为构造函数
        阅读重点
            看到 new Promise、new ArrayBuffer、new Uint8Array、new DataView 或 new TextEncoder 时，应先识别它们是构造调用
            构造调用得到的值仍需要依据对应构造器说明判断其类型和行为

    原型与 class
        原型
            JavaScript 对象可以从原型对象继承属性和方法
            当对象自身没有某个属性时，JavaScript 会沿原型链继续查找
        自有属性与原型属性
            Object.hasOwn(obj, key) 只判断自有属性
            key in obj 会同时检查自有属性和原型链中的属性
        e.g.
            const base = { category: "base" };
            const item = Object.create(base);
            item.name = "Lin";
            console.log(Object.hasOwn(item, "name"));		# true
            console.log(Object.hasOwn(item, "category"));		# false
            console.log("category" in item);		# true
        class
            class 是构造函数和原型机制的语法形式
            class 不会脱离原型机制创建另一套对象模型
        e.g.
            class Counter {
                constructor(start = 0) {
                    this.count = start;
                }
                increment() {
                    this.count += 1;
                    return this.count;
                }
                static zero() {
                    return new Counter(0);
                }
            }
            const counter = Counter.zero();
            console.log(counter.increment());		# 1
            console.log(counter.increment());		# 2
        重点
            class 的实例方法通常位于原型上，而不是每个实例各自保存一份
            static 方法通过类本身调用，不通过实例调用

    控制流与异常
        条件分支
            if、else if、else 根据条件执行不同代码
            switch 可用于多个固定分支
        循环
            for 适合按计数器循环
            for...of 适合遍历可迭代值
            while 在条件为真时重复执行
        短路求值
            && 左侧为假值时不计算右侧
            || 左侧为真值时不计算右侧
            ?? 左侧不是 null 或 undefined 时不计算右侧
        throw
            throw 抛出异常值
            推荐抛出 Error 或其子类实例，便于保留错误信息
        try、catch、finally
            try 包含可能抛出异常的代码
            catch 接收异常
            finally 无论是否发生异常都会执行
        e.g.
            function divide(a, b) {
                if (b === 0) {
                    throw new Error("divisor cannot be zero");
                }
                return a / b;
            }
            try {
                divide(1, 0);
            } catch (error) {
                console.log(error.message);		# divisor cannot be zero
            } finally {
                console.log("finished");		# finished
            }
        重点
            catch 只能处理其 try 范围内同步抛出的异常，以及被 await 的 Promise 拒绝
            未被 await 或未返回的异步任务可能不会被当前 try/catch 捕获

    ArrayBuffer、TypedArray 与 DataView
        ArrayBuffer
            ArrayBuffer 是固定长度的原始二进制缓冲区
            ArrayBuffer 不是普通数组，不能直接用 [0] 读写字节
            精确来说，ArrayBuffer 实例可以是固定长度，也可以是可调整长度
            上面的“固定长度”只描述默认的 new ArrayBuffer(byteLength) 创建方式和本阶段主要示例
            默认使用 new ArrayBuffer(byteLength) 创建的缓冲区长度固定
            现代运行时也可能支持通过 maxByteLength 创建可调整长度的 ArrayBuffer
            可调整长度的 ArrayBuffer 可以通过 resizable、maxByteLength 和 resize() 识别与操作
            本阶段示例只使用默认的固定长度 ArrayBuffer；阅读其他代码时需要先确认当前运行时是否支持可调整长度
        TypedArray
            Uint8Array、Int8Array、Uint16Array、Uint32Array 等是读取 ArrayBuffer 的类型化视图
            Uint8Array 的每个元素代表一个 0 到 255 的无符号字节
        DataView
            DataView 也是 ArrayBuffer 的视图
            DataView 可以按指定端序读取或写入多字节整数和浮点数
        视图范围
            view.byteOffset 表示该视图相对底层 buffer 的起始字节偏移
            view.byteLength 表示该视图覆盖的字节长度
            不同视图可以共享同一个 ArrayBuffer
        e.g.
            const buffer = new ArrayBuffer(4);
            const bytes = new Uint8Array(buffer);
            bytes[0] = 0x12;
            bytes[1] = 0x34;
            console.log(bytes.length);		# 4
            console.log(bytes[0]);		# 18
        端序
            多字节整数在内存中的字节顺序称为端序
            DataView 的 getUint16(offset, false) 使用大端序
            DataView 的 getUint16(offset, true) 使用小端序
        e.g.
            const buffer = new ArrayBuffer(2);
            const bytes = new Uint8Array(buffer);
            bytes[0] = 0x12;
            bytes[1] = 0x34;
            const view = new DataView(buffer);
            console.log(view.getUint16(0, false));		# 4660
            console.log(view.getUint16(0, true));		# 13330
        subarray()
            TypedArray.prototype.subarray() 创建共享同一 ArrayBuffer 的新视图
            subarray() 不复制底层字节
        e.g.
            const source = new Uint8Array([10, 20, 30, 40]);
            const part = source.subarray(1, 3);
            part[0] = 99;
            console.log(source.join(","));		# 10,99,30,40
            console.log(part.byteOffset);		# 1
            console.log(part.byteLength);		# 2
        重点
            part.buffer 可能包含 part 视图范围以外的字节
            需要使用视图数据时，应同时关注 buffer、byteOffset 和 byteLength

    JSON
        概念
            JSON 是文本数据格式，不是 JavaScript 对象本身
            JSON.parse() 把 JSON 文本转换为 JavaScript 值
            JSON.stringify() 把 JavaScript 值转换为 JSON 文本
        e.g.
            const text = '{"name":"Lin","level":2}';
            const user = JSON.parse(text);
            const result = JSON.stringify(user);
            console.log(user.name);		# Lin
            console.log(result);		# {"name":"Lin","level":2}
        JSON 可表示的常见值
            object
            array
            string
            number
            true
            false
            null
        JSON 不能直接表示的 JavaScript 值
            undefined
            function
            symbol
            bigint
            NaN
            Infinity
        stringify() 的常见规则
            对象中值为 undefined、function 或 symbol 的属性会被省略
            数组中的 undefined、function 或 symbol 位置会转换为 null
            默认 JSON.stringify(BigInt) 会抛出 TypeError
            NaN 和 Infinity 在 JSON 中会序列化为 null
        e.g.
            console.log(JSON.stringify({ a: undefined, b: 1 }));		# {"b":1}
            console.log(JSON.stringify([undefined, 1]));		# [null,1]
            console.log(JSON.stringify([NaN, Infinity]));		# [null,null]
        属性顺序
            JSON.stringify() 不是通用的规范化工具
            不能假设它会自动按字母或字典序排序所有属性
            需要比较字节时，必须以实际代码的构造和序列化规则为准
        e.g.
            console.log(JSON.stringify({ b: 2, a: 1 }));		# {"b":2,"a":1}

    Base64 浏览器 API
        btoa()
            btoa() 把二进制字符串编码为 Base64 文本
        atob()
            atob() 把 Base64 文本解码为二进制字符串
        e.g.
            const encoded = btoa("ABC");
            console.log(encoded);		# QUJD
            console.log(atob(encoded));		# ABC
        二进制字符串
            btoa() 和 atob() 处理的是每个码元位于 0 到 255 范围内的二进制字符串
            它们不能直接作为任意 Unicode 文本的 Base64 编解码方案
        重点
            btoa("你") 在浏览器中通常会抛出 InvalidCharacterError
            需要处理 Unicode 文本时，应先明确字符到字节的编码规则，例如使用 TextEncoder
            Base64 本身不是加密，具体分类见第 0 阶段

    Promise
        概念
            Promise 表示一个可能在未来完成或失败的结果
        状态
            pending 表示尚未完成
            fulfilled 表示成功完成
            rejected 表示失败完成
            Promise 一旦变为 fulfilled 或 rejected，状态不能再次改变
        Promise executor
            new Promise(executor) 创建 Promise 时，executor 会同步执行
            .then()、.catch() 和 .finally() 注册的后续处理会在 Promise 完成后安排执行
        e.g.
            console.log("A");		# A
            new Promise((resolve) => {
                console.log("B");		# B
                resolve("done");
            }).then(() => {
                console.log("D");		# D
            });
            console.log("C");		# C
            上述输出顺序是 A、B、C、D
        then()
            then(onFulfilled) 处理成功结果
            then() 返回新的 Promise，因此可以链式调用
        catch()
            catch(onRejected) 处理拒绝结果或链中抛出的异常
        finally()
            finally(callback) 在成功或失败后都执行
            finally() 不接收前一个 Promise 的结果值
        e.g.
            Promise.resolve(2)
                .then((value) => value + 3)
                .then((value) => console.log(value));		# 5
        重点
            Promise 不是线程
            创建 async 函数或 Promise 不会自动创建新线程

    任务与微任务
        调用栈
            同步代码在当前调用栈中从上到下执行
        微任务
            Promise 的 then、catch、finally 后续处理通常进入微任务队列
            当前同步代码执行结束后，运行时会先处理微任务
        任务
            setTimeout 等回调通常作为任务在后续事件循环阶段执行
        e.g.
            console.log("start");		# start
            setTimeout(() => {
                console.log("task");		# task
            }, 0);
            Promise.resolve().then(() => {
                console.log("microtask");		# microtask
            });
            console.log("end");		# end
            上述输出顺序是 start、end、microtask、task
        重点
            await 不会阻塞整个线程
            await 会暂停当前 async 函数后续语句，函数外的同步代码仍可继续执行
            不要把“异步”直接理解为“并行”或“新线程”

    async 与 await
        async 函数
            async function 声明的函数一定返回 Promise
            返回普通值时，该值会成为 fulfilled Promise 的结果
            抛出异常时，返回的 Promise 会变为 rejected
        await
            await 等待一个 Promise 或可被转换为 Promise 的值完成
            await 只能在 async 函数中使用，或在支持顶层 await 的 ES Module 中使用
        e.g.
            async function addAsync(a, b) {
                return a + b;
            }
            addAsync(1, 2).then((value) => {
                console.log(value);		# 3
            });
        try/catch 与 await
            在 async 函数中，await 一个 rejected Promise 会抛出异常
            可以使用 try/catch 处理该异常
        e.g.
            async function readValue() {
                try {
                    const value = await Promise.resolve("ready");
                    return value;
                } catch (error) {
                    return "failed";
                }
            }
            readValue().then((value) => {
                console.log(value);		# ready
            });
        顺序等待与并列等待
            连续写两个 await 时，第二个 await 通常在第一个完成后才开始执行相关语句
            已经创建的多个 Promise 可以交给 Promise.all() 一起等待
        e.g.
            async function sumValues() {
                const first = Promise.resolve(1);
                const second = Promise.resolve(2);
                const [a, b] = await Promise.all([first, second]);
                return a + b;
            }
            sumValues().then((value) => {
                console.log(value);		# 3
            });
        Promise.all()
            所有 Promise 成功时，Promise.all() 返回按输入顺序排列的结果数组
            任意一个 Promise 拒绝时，Promise.all() 返回的 Promise 会拒绝
            Promise.all() 不会自动取消其他已经开始的操作

    ES Module 的导入与导出
        命名导出
            一个模块可以导出多个有名称的值
        默认导出
            一个模块最多有一个默认导出
        导入
            import 从另一个 ES Module 导入公开的值
        e.g.
            math.js
                export const base = 10;
                export function add(a, b) {
                    return a + b;
                }
                export default function multiply(a, b) {
                    return a * b;
                }
            app.js
                import multiply, { base, add } from "./math.js";
                const result = multiply(add(base, 1), 2);
        动态导入
            import("./module.js") 返回 Promise
            动态导入的模块命名空间对象会在 Promise 成功后得到
        CommonJS
            CommonJS 常使用 require() 和 module.exports
            CommonJS 与 ES Module 的加载、作用域和导出语义不同
        重点
            阅读模块代码时，先分清 export、import、require 和 module.exports 分别属于什么模块体系
            本阶段只学习模块语法阅读，不学习打包工具如何改写模块
